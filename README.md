# Cabestan - Cartographie des Bibliothèques

## À propos

Cabestan est un outil de cartographie et d'exploration des bibliothèques universitaires françaises. Il permet de :

- **Visualiser** les RCR (Répertoire des Centres de Ressources) sur une carte interactive
- **Rechercher** des bibliothèques selon de multiples critères :
  - Localisation géographique
  - Types d'établissements
  - Langues des collections
  - Périodes de publication
  - Types de documents
  - Et bien d'autres...
- **Explorer** les collections de livres de chaque bibliothèque
- **Filtrer** les résultats avec des critères précis pour affiner les recherches

L'interface principale s'articule autour d'une carte interactive qui permet de visualiser la répartition géographique des RCR, offrant ainsi une vue d'ensemble du paysage documentaire universitaire français.
